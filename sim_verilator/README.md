# Real-Time Verilator + SDL2 Hardware Simulation

This directory contains the **pure software simulation environment** for the Battle Tanks RV32IM FPGA project. It allows you to run, display, and play the full hardware game in real time (60 FPS) directly on your laptop screen in an interactive window with keyboard controls—**without needing any physical FPGA board, VGA cables, or external monitors**.

---

## 1. How It Works

1. **Hardware Compilation (Verilator):**  
   Verilator translates the full SystemVerilog hardware RTL (RV32IM soft-core processor, M-extension hardware multiplier/divider, collision engine, sprite engine, tile renderer, and pixel priority mixer) into high-performance multi-threaded C++ classes.
2. **Standard 640×480 VGA Output (SDL2):**  
   The C++ harness (`sim_main.cpp`) emulates a physical CRT/LCD monitor listening to the hardware's `vga_hsync`, `vga_vsync`, and `vga_r/g/b[3:0]` pins. It rasterizes each 640×480 frame and renders it to a hardware-accelerated SDL2 window.
3. **Interactive Keyboard Mapping:**  
   Laptop keyboard strokes are mapped in real time directly to the debounced player button inputs (`p1_btn_raw` and `p2_btn_raw`).
4. **Retro PWM Audio:**  
   The 1-bit PWM audio output (`aud_pwm`) generated by the hardware sound engine is downsampled and streamed to your laptop speakers using SDL2 audio.

## 2. Quick Setup & How to Run on Windows

You have two fast ways to run this on your Windows laptop:

### Option A: MSYS2 (Recommended for Native Windows Performance)

MSYS2 builds a native `.exe` that runs directly on Windows with GPU acceleration.

1. **Download & Install MSYS2:**
   If you don't already have MSYS2, download the installer from [msys2.org](https://www.msys2.org) and run it (default directory: `C:\msys64`).

2. **Install Verilator, GCC, Make, and SDL2:**
   Open the **MSYS2 UCRT64** terminal (search for "MSYS2 UCRT64" in Windows Start Menu) and paste:
   ```bash
   pacman -Syu --noconfirm
   pacman -S --noconfirm mingw-w64-ucrt-x86_64-verilator \
                         mingw-w64-ucrt-x86_64-SDL2 \
                         mingw-w64-ucrt-x86_64-gcc \
                         make
   ```

3. **Build & Run:**
   In the MSYS2 UCRT64 terminal, navigate to this directory:
   ```bash
   cd /c/Users/JAYESH/Desktop/jayesh/textbooks/hard_lab/pagal-paanch/sim_verilator
   make -j4
   ./battle_tanks_sim.exe
   ```
   *(Or simply double-click `build_and_run.bat` from Windows File Explorer!)*

---

### Option B: WSL2 (Windows Subsystem for Linux - Ubuntu)

Windows 10/11 supports GUI windows seamlessly from WSL via WSLg.

1. **Install Prerequisites in WSL Terminal:**
   Open your Ubuntu / WSL terminal and run:
   ```bash
   sudo apt update
   sudo apt install -y verilator libsdl2-dev build-essential
   ```

2. **Build & Run:**
   ```bash
   cd /mnt/c/Users/JAYESH/Desktop/jayesh/textbooks/hard_lab/pagal-paanch/sim_verilator
   ./build_and_run.sh
   ```

## 4. Key Design Properties

* **Zero Game Logic Modifications:**  
  The C firmware (`software/src/`) and hardware accelerator logic (`modules/`) remain 100% untouched.
* **Firmware Self-Containment:**  
  By default, the Verilator simulation utilizes the embedded firmware arrays (`modules/cpu/firmware_imem.vh` and `firmware_dmem.vh`), so the resulting executable is completely standalone.
* **Simulation Tuning:**  
  The `sim_top.v` wrapper tunes the cooldown prescaler (`CLK_PER_MS = 1000`) and sets debounce delay to 2 cycles so controls are snappy and responsive when driven by your laptop keyboard.
